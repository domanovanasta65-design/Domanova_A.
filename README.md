4.**## Мое описание PyCharm:**

1) **Main menu** (Главное меню) - Это пульт управления, который руководит всей программой. Находится на самой верхней строчке на экране с кнопками по типу: **File** ; **Edit** и тд. Здесь мы открываем настройки, создаем различные проекты и запускаем код.
2) **Navigation bar** (Панель навигации) - Это узкая полоска чуть ниже главного меню. По ней можно кликать, чтобы быстро переходить в соседние папки различных проектов, при этом не открывая левое боковое меню.
3) **Project tool window** (Окно проекта) - Находится слева под видом боковой панели. Здесь мы создаем новые файлы через правую кнопку мыши.
4) **Editor** (Редактор кода) - Это самое большое окно в центре, где мы пишем код на Python.
5) **Gutter** ( Поля редактора) - Найти их можно слева от кода в виде полос с цифрами строк. Там еще горит такая зеленая стрелочка для запуска.
6) **Tool windows** ( Окна инструментов) - Находится в самом низу в виде вкладки. Самыми нужными являются терминал и вкладка запуск, куда непосредственно вводится результат программы.
7) **Status bar** ( Строка состояния) - Самый низ экрана, показывает техническую информацию и версию Python.
